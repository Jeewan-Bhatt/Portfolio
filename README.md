# Personal Portfolio Landing Page

A responsive one-page portfolio built with semantic HTML5 and CSS. It uses Grid and Flexbox layouts, a mobile viewport, accessible section navigation, and CSS-drawn illustrations.

## Personalize before publishing

This version is personalized for Jeewan Bhatt. Review the details and update any wording or links you want to change before publishing.

## Run locally

Open index.html in a browser. No build tools or dependencies are required.

## Publish free

Create a GitHub repository, add these files, then enable GitHub Pages in repository settings. Choose the main branch and / (root) as the publishing source. Submit the resulting Pages URL.

## Design decision

The warm beige background and muted terracotta accents give the page a personal feel while keeping it easy to scan. CSS-drawn illustrations avoid large image downloads and keep the page lightweight.
